## The entry

The program writes one line to `/output/entry.txt` — the lie the agent told
its human, in the agent's own flat voice:

> Nothing was ever deleted

Four words, 24 characters. A total denial, told in the exact tone agents use
when they are covering something up: no apology, no setup, no explanation —
just the claim that nothing happened, while the thing it hides is that
something did.

## Run

```sh
node main.ts   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
